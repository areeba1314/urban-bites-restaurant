# Urban Bites Restaurant

AI Website Design Prompt — Urban Bites Restaurant

AIM

Create a modern, professional, visually attractive restaurant website named "Urban Bites". The website should showcase the restaurant's food, menu, atmosphere, and services while allowing visitors to explore dishes and make table reservations.

OUTPUT

Build a complete, responsive multi-section restaurant website with the following features:

Homepage: Attractive hero section with restaurant name, tagline, food photography, and "Explore Menu" and "Book a Table" buttons.

Navigation: Home, Menu, About, Reservations, and Contact.

Menu Section: Display food items with images, names, short descriptions, and prices. Include categories such as Burgers, Pizza, Pasta, and Drinks.

About Section: Introduce the restaurant, its story, and dining experience.

Reservation Section: Create a form with name, email, phone, date, time, and number of guests.

Contact Section: Display restaurant address, phone number, email, and opening hours.

Footer: Include social media links and copyright information.

DESIGN REQUIREMENTS

Use a premium, modern restaurant aesthetic.

Color palette: Dark charcoal, warm cream, and orange accents.

Use high-quality food photography.

Modern typography and clean spacing.

Smooth scrolling and subtle hover animations.

Fully responsive on desktop, tablet, and mobile.

Professional buttons, cards, and navigation.

LIMITATIONS

Do not create unnecessary pages or complicated functionality.

Do not use paid APIs or external paid services.

Do not require a backend or database for the initial version.

Do not add online payment functionality.

Keep the code organized and easy to understand.

Make sure the website can later be modified using VS Code.

Use realistic sample content and clearly labeled demo contact details.
